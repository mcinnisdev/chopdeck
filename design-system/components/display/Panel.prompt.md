Panel groups controls under a silkscreen legend; Silkscreen is the label type; Wordmark is the CHOP DECK type lockup.

```jsx
<Panel title="PAD BANK"><HardButton label="A" led="green" ledOn /> …</Panel>
<Silkscreen size="xs">TAP TEMPO / NOTE REPEAT</Silkscreen>
<Wordmark size="lg" onDark />
```

- Use `recessed` for pad grids and cursor clusters; plain outline for button groups.
- `onDark` swaps ink for cream when placed on the navy chassis.
