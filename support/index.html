Support Chop Deck

Chop Deck is free, open source, and carries no ads and no tracking. The machine works without an account and always will. It is built and run by one person, Nick McInnis, and the hosting, storage for everyone's projects and libraries, and the email that signs you in all cost real money every month.

If the machine has earned a place on your desk, a coffee goes a long way.

Buy me a coffee

Every coffee is a thank-you, not a subscription, and it unlocks nothing: there are no premium features and there will not be a paywall on the instrument.

Other ways to help

  • Publish. A kit, a sample from a record in the public domain, or a beat. The libraries are only as good as what people put in them.
  • Report what breaks. The owner's manual is the spec; if the machine does not do what the manual says, that is a bug. Write to hello@chopdeck.com.
  • Build on it. The whole thing is open source on GitHub. Fork it, run it offline, make it yours. The README explains how.
  • Tell a beatmaker. Send them chopdeck.com.
